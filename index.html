About me

Frontend focus, fullstack reach.

My colleagues would describe me as calm, witty and an active listener. I'm a Senior Front-End / Full-Stack Developer at Diff Agency in Montréal, where I lead delivery of Shopify ecommerce solutions for high-traffic brands.

Day to day I set front-end architecture in React, TypeScript and the Shopify APIs, build reusable components for complex shopping experiences, integrate backend services and third-party apps, and review code and mentor the developers around me.

I came to code from CRM and marketing, so I think about conversion, segmentation and A/B tests as much as clean components. I also use AI tools throughout the development cycle, paired with code review and testing, to ship maintainable work faster.
